# Конструктор сцен — Godot-сцены мода с живым предпросмотром

Конструктор сцен правит Godot-сцены мода (`.tscn`: панели, части HUD, баннеры) поверх работающего экрана игры. Вы видите сцену там, где она появится, перетаскиваете её узлы, меняете их свойства в инспекторе, а файл записывается обратно без потери тех частей, которые конструктор не показывает.

## Как открыть

Кнопка с молотком на игровом тулбаре → **Конструктор сцен**.

## Правка сцены

1. Первый список — базовая сцена, поверх которой показывается сцена мода (или пустая).
2. **Мод** и **Сцена мода (.tscn)** — файл для правки.
3. Выберите узел кликом в предпросмотре или в **Иерархии**. Золотым выделен корень сцены мода, яркие узлы можно править, бледные принадлежат базовой сцене и только для чтения.
4. Перетаскивайте узел за тело или за ручки либо меняйте его свойства в **Инспекторе** (числа, текст, цвета, переключатели, позиции). Правки инспектора и ручек сохраняются сами.
5. Добавьте узел выбранного типа в выделенный узел или удалите выделенный узел вместе с детьми (Del).
6. Вкладка **Исходник .tscn** показывает текст; ручные правки в нём сохраняются по Ctrl+S, который заодно перестраивает предпросмотр. **Перечитать с диска** отбрасывает несохранённые правки.

В файле переписываются только изменённые значения; ресурсы, связи сигналов и свойства, которых инспектор не знает, остаются как были.

## Ограничения

- Только моды-папки; упакованный мод сохранить нельзя («мод только для чтения»).
- Узлы базовой сцены показаны для ориентира и никогда не записываются.

## Зависимости

`tools_base`, `ui_base`.
Старый пакет `editor_tools` ставит этот мод вместе с остальными авторскими окнами.
