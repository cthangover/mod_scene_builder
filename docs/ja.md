# シーンビルダー — ライブプレビュー付きで MOD の Godot シーンを編集

シーンビルダーは、動いているゲーム画面の上で MOD の Godot シーン（`.tscn`: パネル、HUD の部品、バナー）を編集します。シーンが実際に現れる場所で見ながらノードをドラッグし、インスペクターでプロパティを変えると、ビルダーが表示しない部分を失わずにファイルへ書き戻されます。

## 開き方

ゲームのツールバーのハンマーボタン → **シーンビルダー**。

## シーンの編集

1. 最初のリストは MOD のシーンを重ねる基本シーン（または空のシーン）です。
2. **MOD** と **MOD のシーン（.tscn）** — 編集するファイル。
3. プレビューか**階層**でクリックしてノードを選びます。金色は MOD シーンのルート、明るいノードは編集可能、薄いノードは基本シーンのもので読み取り専用です。
4. ノードを本体かハンドルでドラッグするか、**インスペクター**でプロパティ（数値、テキスト、色、スイッチ、位置）を変えます。インスペクターとハンドルの変更は自動で保存されます。
5. 選んだノードの中に選択した種類のノードを追加するか、選んだノードを子ごと削除します（Del）。
6. **.tscn ソース**タブはテキストを表示します。手での変更は Ctrl+S で保存され、プレビューも作り直されます。**ディスクから読み直す**は未保存の変更を捨てます。

ファイルでは変更された値だけが書き換えられ、インスペクターが知らないリソース、接続、プロパティはそのまま残ります。

## 制限

- フォルダー MOD のみ。パックされた MOD は保存できません（「MOD は読み取り専用です」）。
- 基本シーンのノードは目安として表示されるだけで、書き込まれることはありません。

## 依存関係

`tools_base`、`ui_base`。
古い `editor_tools` パッケージは、この MOD をほかの作成用ウィンドウと一緒にインストールします。
