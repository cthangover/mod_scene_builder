# 场景构建器 —— 带实时预览的模组 Godot 场景

场景构建器在运行中的游戏画面上编辑模组的 Godot 场景（`.tscn`：面板、HUD 部件、横幅）。你能在场景实际出现的位置看到它，拖动它的节点，在检查器里修改属性，文件写回时不会丢失构建器不显示的部分。

## 打开方式

游戏工具栏上的锤子按钮 → **场景构建器**。

## 编辑场景

1. 第一个列表是显示模组场景的基础场景（或空场景）。
2. **模组**和**模组场景（.tscn）**——要编辑的文件。
3. 在预览中或在**层级**里点击来选择节点。金色是模组场景的根，明亮的节点可编辑，暗淡的节点属于基础场景，只读。
4. 拖动节点本体或手柄，或在**检查器**中修改属性（数字、文本、颜色、开关、位置）。检查器和手柄的修改会自动保存。
5. 往选中的节点里添加所选类型的节点，或删除选中的节点及其子节点（Del）。
6. **.tscn 源码**标签页显示文本；手动修改用 Ctrl+S 保存，同时重建预览。**从磁盘重新加载**会丢弃未保存的修改。

文件中只改写变化了的值；检查器不认识的资源、连接和属性保持原样。

## 限制

- 仅限文件夹模组；打包的模组无法保存（“模组为只读”）。
- 基础场景的节点只作参照显示，永远不会被写入。

## 依赖

`tools_base`、`ui_base`。
旧的 `editor_tools` 包会把这个模组和其他创作窗口一起安装。
