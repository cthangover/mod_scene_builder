# 장면 빌더 — 실시간 미리보기로 모드의 Godot 장면 편집

장면 빌더는 실행 중인 게임 화면 위에서 모드의 Godot 장면(`.tscn`: 패널, HUD 조각, 배너)을 편집합니다. 장면이 실제로 나타날 자리에서 보면서 노드를 끌고 인스펙터에서 속성을 바꾸면, 빌더가 보여 주지 않는 부분을 잃지 않고 파일에 다시 기록됩니다.

## 여는 방법

게임 툴바의 망치 버튼 → **장면 빌더**.

## 장면 편집

1. 첫 번째 목록은 모드 장면을 겹쳐 보여 줄 기본 장면(또는 빈 장면)입니다.
2. **모드**와 **모드 장면 (.tscn)** — 편집할 파일.
3. 미리보기나 **계층**에서 클릭해 노드를 고릅니다. 금색은 모드 장면의 루트, 밝은 노드는 편집 가능, 흐린 노드는 기본 장면의 것으로 읽기 전용입니다.
4. 노드를 몸체나 핸들로 끌거나 **인스펙터**에서 속성(숫자, 텍스트, 색, 스위치, 위치)을 바꿉니다. 인스펙터와 핸들 편집은 저절로 저장됩니다.
5. 선택한 노드 안에 고른 종류의 노드를 추가하거나, 선택한 노드를 자식과 함께 삭제합니다(Del).
6. **.tscn 소스** 탭은 텍스트를 보여 줍니다. 직접 고친 내용은 Ctrl+S로 저장되며 미리보기도 다시 만들어집니다. **디스크에서 다시 읽기**는 저장하지 않은 편집을 버립니다.

파일에서는 바뀐 값만 다시 쓰이고, 인스펙터가 모르는 리소스, 연결, 속성은 그대로 남습니다.

## 제한

- 폴더 모드만 가능하며, 패키지된 모드는 저장할 수 없습니다("모드가 읽기 전용입니다").
- 기본 장면의 노드는 참고용으로만 보이며 절대 기록되지 않습니다.

## 의존성

`tools_base`, `ui_base`.
예전 `editor_tools` 패키지는 이 모드를 다른 제작 창과 함께 설치합니다.
